ℹ️ About

What Is Novelty Detection?

Novelty detection is a Machine Learning technique used to identify data points that differ significantly from previously observed normal data. Unlike supervised anomaly detection, novelty detection trains only on normal examples and flags anything that deviates from the learned distribution.

This system uses the Isolation Forest algorithm — a tree-based, unsupervised method that detects anomalies by measuring how quickly a data point can be isolated in a random tree structure.

💡 Example: If most machine temperature readings are between 20°C and 30°C and the system suddenly receives 95°C, the model identifies it as a Novel / Unusual Pattern because it requires fewer splits to isolate.

Isolation Forest uses a contamination parameter (set to 0.05 here) to tune the decision boundary. The model is trained entirely on synthetic normal sensor data and saved using Joblib for fast loading.
